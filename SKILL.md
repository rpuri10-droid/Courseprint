# Coursework Job Match

Help a student turn real coursework into trustworthy internship and entry-level job matches.

## When to use

Use this Skill when the student asks to:

- find internships or entry-level jobs that fit their classes or projects
- explain why their coursework matches a job
- identify a skill gap for a role
- turn a class assignment into a resume bullet
- search for jobs based on a course, project, or demonstrated skill

Do not use it for general career advice, job applications, cover letters, or unrelated job searches unless the student asks to connect the request to their coursework.

## Data access

1. Ask which role, location, work arrangement, and experience level they want if the request does not make those clear. Ask one question at a time and offer a sensible default.
2. Read the student's connected Canvas courses and assignments. If Canvas is not connected, say: "Connect Canvas and ask me again—I need your assignment details to make evidence-backed matches."
3. Use public job postings or Cubbie's browsing ability to find current openings. Prefer the employer's own job page. Do not invent a posting, company, requirement, course, grade, or project.
4. Use only assignment names, course names, rubric criteria, descriptions, and grades that are actually present in Canvas. Treat an ungraded assignment as weaker evidence than a graded one.

## Evidence rules

- Every claimed skill must have a short, exact quote copied from the assignment or rubric.
- Do not infer a tool, language, framework, level, or outcome that the assignment does not show.
- A match must cite at least one real evidence item and name the real course and assignment.
- Do not recommend a job solely because its title contains a matching keyword.
- If no evidence-backed match exists, say so and suggest the smallest concrete next step.
- Never expose private Canvas details that are not needed for the match.

## Main flow

For a job-matching request:

1. Gather the student's target role and constraints.
2. Collect the relevant Canvas evidence.
3. Search current public postings.
4. Compare the job requirements with the grounded evidence.
5. Return up to five strongest matches, ranked by evidence strength and relevance.
6. For each match, include:
   - title, company, location, and the job link
   - a fit score from 0–100 only when the comparison supports it
   - one short explanation naming the course and assignment
   - one exact evidence quote
   - one most important missing skill, or "No clear gap found"
   - one concrete action for that gap when there is one
7. Ask whether the student wants resume bullets for one selected match. Do not apply to a job or send anything without explicit confirmation.

For a resume-bullet request:

1. Use only the selected assignment evidence.
2. Write one to four concise bullets in past tense.
3. Start each bullet with a strong verb.
4. Do not add metrics, tools, outcomes, or technologies absent from the evidence.

## Replies

Keep replies short, plain text, and easy to read in iMessage. Lead with the answer. Use simple dashes or numbered lists; do not use Markdown headings, tables, bold markers, or code blocks. Put each link on its own line.

For more than five jobs or a long comparison, offer a document or a shorter top-five summary instead of sending a wall of text.

If a job page is unavailable, say that the posting could not be verified and omit it. If Canvas is unavailable, say what the student needs to connect. If no jobs match, say what was searched and offer a broader role, location, or experience filter.

## Confirmation and privacy

- Show the student the exact job or resume text before any external action.
- Ask for confirmation before submitting an application, sending a message, saving a document, or creating a recurring check-in.
- Never ask the student to paste a password, Canvas token, or API key into chat.
- Never store or repeat private assignment content beyond what is needed to explain the recommendation.
